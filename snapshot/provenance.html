The adversary switch

Reject a class of source, and recount

The commonest objection to a record like this one is not that a figure is wrong. It is that a class of source cannot be trusted. The answer here is not to defend the source but to remove it. Each setting deletes every body of that class and recounts what is left: a claim stands if it still has one source outside the classes removed, and falls if it does not. Nothing else on the page changes.
